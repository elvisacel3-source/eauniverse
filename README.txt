2. Test the live site on a phone and computer, especially the WhatsApp and email buttons.
3. A custom domain such as eauniverse.com is only a suggestion; availability and price have not been verified. Custom domains normally cost money even if hosting is free.
4. Online checkout is NOT connected. Before taking payments, create a merchant account with a suitable provider (for example, Paystack in Ghana), verify account eligibility and fees, add real product names/prices, and connect the actual checkout links. Do not publish placeholder checkout buttons.
5. The enquiry form does not store messages in a database; it opens the visitor's email app. Some visitors may not have an email app configured.
6. Add clear terms, privacy information, refund/delivery policy, and accurate product details before selling. Avoid promising guaranteed income.

Suggested free-hosting route
- Create or sign in to a GitHub account.
- Create a public repository named ea-universe-site.
- Upload index.html to the repository root.

- GitHub will show the published URL after deployment. The exact URL depends on the GitHub username.
